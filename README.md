# 3U Save Tools (Linux / GUI Edition)

Una interfaz gráfica (GUI) para la conversión de partidas guardadas de **Monster Hunter 3 Ultimate (MH3U)** entre **Nintendo 3DS** y **Wii U**, adaptada y optimizada para entornos **Linux**.

Este proyecto es una adaptación y extensión del prototipo original creado por [@fadillzzz](https://github.com/fadillzzz/3usavetools).

---

## Advertencia

Esta herramienta realiza conversiones directas en archivos de guardado. Aunque el proceso es funcional, **siempre realiza una copia de seguridad (backup) de tus archivos de guardado** antes de realizar cualquier conversión.

---

## Características

- **Soporte y enfoque en Linux:** Adaptado para ejecutar de forma nativa e integrada en distribuciones Linux con **`Interfaz Gráfica`** sin necesidad de usar la línea de comandos.
- **Conversión Bireccional:**
  - 3DS -> Wii U
  - Wii U -> 3DS
